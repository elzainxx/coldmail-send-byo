# ranges.txt — the SMTP host destination guard's blocked-range table (Phase 3 close-out C4). THE canonical table.
#
# One row per line, three pipe-delimited fields:  CIDR|kind|name
#   kind  block     the whole range is refused;
#         embedded  the address CARRIES an IPv4 address (IPv4-mapped, NAT64, 6to4): the range is not refused as such,
#                   the embedded IPv4 address is judged against the IPv4 rows instead (so a mapped loopback is refused
#                   and a mapped public address is not).
#   name  what the range is, for the log and the docs; it never reaches a response body.
#
# The Control embeds this file (hostguard.go), the worker keeps the same rows in services/worker/src/destguard.js, and a
# test on each side parses THIS file and fails if its own table is not row-for-row the same (set equality, both
# directions), so a range can be removed from neither without this file saying so. A range removed from a table turns
# the table test red (the row is missing) AND the behaviour test red (the range's own first, last and middle address are
# no longer refused).
#
# On top of the rows, one rule that is not a row: an IPv6 address outside 2000::/3 (not global unicast) is refused too,
# so an unlisted corner of the non-global IPv6 space cannot be reached.
#
# A name that resolves to ANY refused address is refused as a whole (the guard never connects to the passing addresses
# of a mixed answer). The allowlist dial smtp_host_allow_cidrs is checked AFTER the embedded-address judgement and
# overrides a refused row for the addresses it names, and for nothing else.
